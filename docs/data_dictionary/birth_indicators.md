# Dicionário dos indicadores de nascimento

Chaves: `nivel_territorial`, `ano`, `codigo_territorio` e `territorio`.
Os níveis são Brasil, região, estado e município de residência.

| Campo | Definição |
|---|---|
| `nascidos_vivos` | Total de registros SINASC |
| `tipo_parto_informado` | Denominador com parto válido |
| `nascidos_vivos_parto_vaginal` | Partos vaginais |
| `nascidos_vivos_parto_cesareo` | Cesáreas |
| `percentual_cesareas` | Cesáreas / tipo de parto informado x 100 |
| `gestacao_informada` | Denominador com 20 a 45 semanas |
| `nascidos_vivos_prematuros` | Nascimentos com 20 a 36 semanas |
| `percentual_prematuridade` | Prematuros / gestação informada x 100 |
| `peso_informado` | Denominador com peso válido |
| `nascidos_vivos_baixo_peso` | Peso menor que 2.500 g |
| `percentual_baixo_peso` | Baixo peso / peso informado x 100 |
| `peso_medio_g` | Média do peso válido em gramas |
| `apgar5_informado` | Denominador com Apgar no quinto minuto |
| `apgar5_menor_7` | Apgar no quinto minuto menor que 7 |
| `percentual_apgar5_menor_7` | Apgar baixo / Apgar informado x 100 |
| `prenatal_informado` | Denominador com consultas informadas |
| `prenatal_7_mais` | Sete ou mais consultas |
| `percentual_prenatal_7_mais` | Sete ou mais / pré-natal informado x 100 |
| `idade_mae_informada` | Denominador com idade materna válida |
| `nascidos_vivos_maes_adolescentes` | Idade materna menor que 20 anos |
| `nascidos_vivos_idade_materna_avancada` | Idade materna de 35 anos ou mais |
| `tipo_gravidez_informado` | Denominador com tipo de gravidez válido |
| `nascidos_vivos_gestacao_multipla` | Gravidez dupla ou de ordem superior |
