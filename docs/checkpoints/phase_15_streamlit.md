# Checkpoint - Fase 15 Streamlit

FASE: 15 - Dashboard Streamlit.

Objetivo: disponibilizar uma interface analítica sobre a API aprovada, sem
consultar diretamente arquivos ou tabelas internas.

Implementado: oito áreas para visão geral, nascimentos, parto e pré-natal,
recém-nascidos, morbidades maternas, mortalidade, comparação estadual e
qualidade. Há filtros territoriais, séries mensais, mapa estadual e tabelas.

Privacidade: somente Brasil, região e UF são apresentados. O município é
mantido fora da interface até existir regra formal de supressão de células.

Validações: resposta real da API, gráficos Plotly carregados, nenhuma mensagem
de erro ou rolagem horizontal e capturas em 1440x1000 e 390x844.

Status: CONCLUÍDA.
