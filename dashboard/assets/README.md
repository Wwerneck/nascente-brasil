# Malha estadual do Brasil

Arquivo `brazil_states.geojson` obtido da API de Malhas do IBGE, com qualidade
mínima e subdivisão por UF. A geometria simplificada contém 27 feições e é
incorporada ao dashboard para que o mapa funcione sem acesso externo.

Fonte:
`https://servicodados.ibge.gov.br/api/v3/malhas/paises/BR?formato=application/vnd.geo%2Bjson&qualidade=minima&intrarregiao=UF`
